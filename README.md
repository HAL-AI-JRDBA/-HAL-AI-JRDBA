# HALL-AI — Interactive Product Preview

A static, multilingual product demonstration for the HALL-AI project by AJDS Informatica LTDA (Brazil).

This preview is **not connected to an LLM, Ollama, private enterprise databases, or external AI APIs**. It illustrates proposed workflows, sample requests and product capabilities. Features are under development and not all are production-ready.

## Publishing

Upload this `README.md` and `index.html` to the root of a Hugging Face Space. The `sdk: static` configuration makes Hugging Face serve `index.html` without requiring paid compute.
